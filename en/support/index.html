Support

Write to us: destek@mm-apps.com · we usually reply within 2 working days

If you include your device model, iOS version and the version line at the bottom of the game's Settings screen, we can solve the problem faster. A screenshot helps a lot too.

Common questions

Does the game show ads?

There are no forced ads. This version of the game has no ads at all.

Can I play without internet?

Yes, for a while. The game lets you fight offline with the run tickets waiting on your device; the results are verified on the server when you are back online and the rewards arrive then. When the tickets run out, offline battles give no rewards. The daily trial and the store need a connection.

A battle's reward did not arrive

The server grants rewards after replaying and verifying the battle's recording. On a slow connection this can take a few minutes. Keep the game open while online; a result that cannot be verified does not count.

Diamonds I bought did not arrive

Diamonds are added to your account once Apple confirms the purchase; on a slow connection this can take a few minutes. If the game says the purchase is waiting for approval (for example with Ask to Buy), they are added when it is approved. If they still have not arrived, write to us with the order number from your Apple receipt.

My diamond balance is below zero

When Apple refunds a purchase, the diamonds it granted are deducted from your balance. If you had already spent them, the balance goes below zero and new diamonds you earn cover it first. This never creates a debt you have to pay.

My progress is not on my new phone

For now your account is tied to the device it was created on; this version has no way to move progress to another device.

Game language

Change it in Settings → Language. The new language appears after you close and reopen the game.

I want a refund

Apple takes the payment for in-app purchases; you can request a refund at reportaproblem.apple.com.

I found a bug or a security issue

Please write to destek@mm-apps.com. If you tell us how to reproduce it, we will look at it right away.
