Wenn du dein Gerätemodell, deine iOS-Version und die Versionszeile unten im Bildschirm „Optionen“ des Spiels angibst, können wir das Problem schneller lösen. Ein Screenshot hilft ebenfalls sehr.

Häufige Fragen

Zeigt das Spiel Werbung?

Es gibt keine Zwangswerbung. Diese Version des Spiels enthält überhaupt keine Werbung.

Kann ich ohne Internet spielen?

Ja, eine Zeit lang. Mit den Lauftickets, die auf deinem Gerät bereitliegen, kannst du offline kämpfen; die Ergebnisse werden auf dem Server geprüft, sobald du wieder online bist, und dann kommen auch die Belohnungen an. Sind die Tickets aufgebraucht, bringen Offline-Kämpfe keine Belohnung. Die Schicksalsprobe und der Shop brauchen eine Internetverbindung.

Die Belohnung für einen Kampf ist nicht angekommen

Der Server schreibt Belohnungen gut, nachdem er die Aufzeichnung des Kampfes erneut abgespielt und geprüft hat. Bei einer langsamen Verbindung kann das ein paar Minuten dauern. Lass das Spiel geöffnet, während du online bist; ein Ergebnis, das sich nicht prüfen lässt, zählt nicht.

Gekaufte Diamanten sind nicht angekommen

Diamanten werden deinem Konto gutgeschrieben, sobald Apple den Kauf bestätigt; bei einer langsamen Verbindung kann das ein paar Minuten dauern. Meldet das Spiel, dass der Kauf auf Bestätigung wartet (zum Beispiel, wenn die „Kaufanfrage“ aktiv ist), werden sie gutgeschrieben, sobald er bestätigt ist. Sind sie dann immer noch nicht da, schreib uns und gib die Bestellnummer aus deinem Apple-Kaufbeleg an.

Mein Diamantenguthaben ist negativ

Wenn Apple einen Kauf erstattet, werden die damit gutgeschriebenen Diamanten von deinem Guthaben abgezogen. Hattest du sie schon ausgegeben, wird das Guthaben negativ, und neu verdiente Diamanten gleichen das zuerst aus. Daraus entstehen nie Schulden, die du bezahlen musst.

Auf meinem neuen Handy fehlt mein Fortschritt

Derzeit ist dein Konto an das Gerät gebunden, auf dem es angelegt wurde; diese Version bietet keine Möglichkeit, den Fortschritt auf ein anderes Gerät zu übertragen.

Spielsprache

Du änderst sie unter Optionen → Sprache. Die neue Sprache erscheint, wenn du das Spiel schließt und neu öffnest.

Ich möchte eine Erstattung

Die Zahlung für In-App-Käufe wickelt Apple ab; eine Erstattung kannst du unter reportaproblem.apple.com beantragen.

Ich habe einen Fehler oder eine Sicherheitslücke gefunden

Bitte schreib an destek@mm-apps.com. Wenn du beschreibst, wie sich das Problem nachstellen lässt, sehen wir es uns sofort an.
